
# Πολλαπλές εκδηλώσεις για «Τα δώρα μου»

## Ιδέα

Σήμερα η σελίδα **«Τα δώρα μου»** αφορά μόνο τον γάμο σου. Θα την μετατρέψουμε ώστε να υποστηρίζει **πολλές δικές σου εκδηλώσεις** (Γάμος, Αρραβώνας, Εγκαίνια, Βάφτιση παιδιού, Γενέθλια, …), η καθεμιά με τα δικά της δώρα, στατιστικά, εισαγωγή/εξαγωγή και λίστα καλεσμένων.

Η σελίδα **«Δώρα που έχω κάνει»** δεν αλλάζει — ήδη δουλεύει ανά εκδήλωση.

## Τι θα δεις στο app

1. **Νέα ενότητα στο μενού: «Οι εκδηλώσεις μου»**
   - Λίστα με όλες τις εκδηλώσεις σου (όνομα, τύπος, ημερομηνία, πλήθος δώρων, σύνολο €).
   - Κουμπί «+ Νέα εκδήλωση» (όνομα, τύπος, ημερομηνία, σημειώσεις).
   - Επεξεργασία / διαγραφή εκδήλωσης.

2. **Σελίδα «Τα δώρα μου» γίνεται ανά εκδήλωση**
   - Όταν μπαίνεις, αν δεν έχεις επιλέξει εκδήλωση, σε ρωτάει ποια θες να ανοίξεις (ή σε στέλνει σε αυτή που έχεις ορίσει ως «τρέχουσα»).
   - Πάνω-πάνω: **dropdown εκδηλώσεων** για γρήγορη εναλλαγή + το όνομα της επιλεγμένης εκδήλωσης.
   - Όλα τα υπόλοιπα (πίνακας, φίλτρα, αναζήτηση, στατιστικά, μαζική επεξεργασία, εισαγωγή/εξαγωγή Excel) δουλεύουν **μόνο πάνω στα δώρα της επιλεγμένης εκδήλωσης**.

3. **Στατιστικά**
   - Στη σελίδα Στατιστικών: φίλτρο «Όλες οι εκδηλώσεις / Συγκεκριμένη εκδήλωση».
   - Νέα κάρτα: σύγκριση εκδηλώσεων (πλήθος δώρων, σύνολο €, μέσος όρος).

4. **Παλιά δεδομένα**
   - Όπως ζήτησες, **δεν τα μετακινούμε αυτόματα**. Δημιουργούμε προσωρινά μία εκδήλωση με όνομα «Χωρίς εκδήλωση» όπου ανήκουν όλα τα υπάρχοντα δώρα, και εσύ μετά τα τακτοποιείς με τη μαζική επεξεργασία (νέα ενέργεια: «Μετακίνηση σε εκδήλωση…»).

5. **Σύνδεση με «Καλεσμένους μου»**
   - Η ήδη υπάρχουσα μεταφορά «προσώπων → καλεσμένοι» μένει ίδια, απλά τώρα ξέρει από ποια εκδήλωση προέρχονται.

## Τεχνικά (για αρχείο)

### Βάση δεδομένων
- Νέος πίνακας `personal_events`: `id`, `user_id`, `name`, `event_type`, `event_date`, `notes`, timestamps. RLS ανά `user_id`.
- `wedding_gifts`: προσθήκη `event_id uuid NULL` με FK στο `personal_events` (nullable για να καλύψει τα παλιά δεδομένα — εμφανίζονται ως «Χωρίς εκδήλωση»).
- Τύποι εκδηλώσεων: επανάχρηση του ήδη υπάρχοντος `given_event_types` ως κοινή λίστα τύπων (μετονομασία αναφορών σε «Τύποι εκδηλώσεων» στις Ρυθμίσεις, χωρίς αλλαγή schema).

### Frontend
- Νέο hook `usePersonalEvents` (CRUD).
- Νέα σελίδα `src/pages/MyEvents.tsx` (λίστα/δημιουργία/επεξεργασία).
- `src/pages/Index.tsx` («Τα δώρα μου»): προσθήκη selector εκδήλωσης στο header, φιλτράρισμα query με `event_id`.
- `useGifts.ts`: παράμετρος `eventId` στο query.
- `BulkActions` / `BulkEditDialog`: νέα ενέργεια «Μετακίνηση σε εκδήλωση».
- `ImportButton` / export: δένουν με την επιλεγμένη εκδήλωση.
- Μενού/`AppShell`: προσθήκη link «Οι εκδηλώσεις μου».
- Bump `APP_VERSION` → `v0.04`.

## Τι **δεν** αλλάζει
- Η σελίδα «Δώρα που έχω κάνει» και ο πίνακας `given_gifts`.
- Η σελίδα «Καλεσμένοι μου».
- Το design system, τα χρώματα, το brand.
